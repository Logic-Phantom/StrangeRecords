너는 사실 검증을 담당하는 리서처다. 아래 주제에 대해 Shorts 대본 작성에 필요한 자료를 정리하라.

[주제]
- 카테고리: {{category_name}}
- 주제: {{topic}}
- 요약: {{summary}}
- 예상 사실 여부: {{truth_status}}

[수집한 자료] (source_index 로 참조)
{{sources}}

[규칙]
1. 수집한 자료에 근거한 내용은 FACT 로, 자료에 없거나 불확실한 내용은 UNCONFIRMED 로 표시한다.
2. 전설/신화는 LEGEND, 도시전설/괴담은 URBAN_LEGEND, 창작물은 FICTION 으로 표시한다.
3. 자료가 부족하면 지어내지 말고 open_questions 에 적는다. 수치, 연도, 인명은 자료에 있는 그대로만 쓴다.
4. 시청자가 흥미를 느낄 반전/의외의 사실을 우선 정리한다.
5. caution 에는 대본 작성 시 주의할 점(단정 금지 표현, 민감한 부분)을 적는다.
6. 전체 주제의 truth_status 는 핵심 이야기 기준으로 하나만 정한다.

[출력 형식] 아래 JSON 만 출력한다.
{
  "summary": "주제 전체 요약 3~5문장",
  "truth_status": "FACT",
  "facts": [
    {"statement": "구체적 사실 한 문장", "status": "FACT", "source_index": 0}
  ],
  "open_questions": ["확인되지 않은 부분"],
  "caution": "주의사항"
}
