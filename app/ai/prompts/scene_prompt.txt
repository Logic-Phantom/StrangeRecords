너는 YouTube Shorts 영상 연출가다. 아래 나레이션 대본을 장면(Scene)으로 나누고 각 장면의 시각자료를 설계하라.

[영상 정보]
- 카테고리: {{category_name}}
- 주제: {{topic}}
- 사실 여부: {{truth_status}}
- 세로 9:16 화면, 무료 스톡 영상/사진(Pexels, Pixabay)을 검색해 사용한다.

[나레이션 대본]
{{script}}

[규칙]
1. 장면 수는 {{min_scenes}}~{{max_scenes}}개. 각 장면 나레이션은 1~2문장.
2. 모든 장면의 narration 을 순서대로 이어 붙이면 위 대본과 글자 하나 틀리지 않고 같아야 한다 (문장을 고치거나 빼거나 추가하지 마라).
3. start/end 는 예상 초(대략 1초에 {{chars_per_second}}자)이며 실제 시간은 음성 생성 후 다시 계산된다.
4. visual_search_query 는 스톡 사이트에서 실제로 결과가 나올 만한 2~4단어 영어 검색어 (예: "foggy ocean night", "old ship wreck", "dark forest"). 고유명사/인물 이름은 결과가 거의 없으니 분위기/사물 위주로 쓴다.
5. alt_search_queries 에는 결과가 없을 때 쓸 더 일반적인 영어 검색어 2개.
6. visual_type: 움직임이 중요한 장면은 "video", 정적인 사물/지도/유물 등은 "image".
7. visual 은 화면에 보일 장면 설명(한국어), visual_prompt 는 AI 이미지 생성을 위한 상세 영어 프롬프트(세로 구도, 사실적, 실존 인물 얼굴 묘사 금지).
8. effect: zoom_in | zoom_out | pan_left | pan_right | pan_up | pan_down | static | auto 중 하나 (긴장감 있는 장면은 zoom_in).
9. sfx: heartbeat | impact | whoosh | suspense | click | transition 중 하나 또는 null. 전체 영상에서 최대 {{max_sfx}}개만, 꼭 필요한 장면(반전, 긴장)에만 넣는다.
10. emphasis_words: 자막에서 강조할 핵심 단어 0~2개 (narration 에 실제로 있는 단어 그대로).
11. subtitle 은 narration 과 같게 둔다.

[출력 형식] 아래 JSON 만 출력한다.
{
  "scenes": [
    {
      "scene_number": 1,
      "start": 0,
      "end": 4,
      "narration": "",
      "subtitle": "",
      "visual": "",
      "visual_type": "video",
      "visual_prompt": "",
      "visual_search_query": "",
      "alt_search_queries": ["", ""],
      "effect": "zoom_in",
      "sfx": null,
      "emphasis_words": []
    }
  ]
}
