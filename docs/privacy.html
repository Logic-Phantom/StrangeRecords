개인정보처리방침 (Privacy Policy)

시행일: 2026-10-10 · 대상 앱: 기묘한 기록 (StrangeRecords)

1. 개요

기묘한 기록(이하 "앱")은 채널 운영자 본인이 자신의 YouTube 채널에 Shorts 영상을 자동으로 업로드하기 위해 사용하는 개인용 도구입니다. 앱은 일반 사용자를 대상으로 하지 않으며, 운영자 이외의 사람의 Google 계정이나 개인정보에 접근하지 않습니다.

2. 사용하는 Google 사용자 데이터

  • YouTube Data API v3 – youtube.upload: 앱이 제작한 영상과 제목·설명·태그를 운영자 본인 채널에 업로드합니다.
  • YouTube Data API v3 – youtube.readonly: 업로드한 영상의 공개 상태와 채널 이름을 확인합니다.

앱은 위 목적 외에 Google 사용자 데이터를 사용하지 않으며, 광고·프로파일링·제3자 판매에 사용하지 않습니다.

3. 저장 및 보관

  • OAuth 인증 토큰은 운영자의 컴퓨터와 운영자 소유 GitHub 저장소의 암호화된 Secrets 에만 저장됩니다.
  • 앱은 운영자 계정의 비밀번호를 저장하지 않습니다.
  • 제작 이력(주제, 업로드한 영상 ID)은 중복 주제 방지를 위해 앱의 데이터베이스에 보관됩니다.

4. 제3자 제공

Google 사용자 데이터는 제3자에게 제공하지 않습니다. 영상 제작 과정에서 대본 생성(Google Gemini API), 음성 합성(Microsoft Edge TTS), 이미지 생성(Hugging Face) 서비스를 사용하지만, 이 서비스들에는 YouTube 계정 정보가 전달되지 않습니다.

5. 권한 철회 및 삭제

운영자는 Google 계정 → 서드파티 앱 및 서비스 에서 언제든지 앱의 접근 권한을 철회할 수 있으며, 철회 시 저장된 토큰은 더 이상 사용할 수 없습니다. 운영자가 로컬 파일과 GitHub Secrets 의 토큰을 삭제하면 앱이 보유한 인증 정보는 모두 삭제됩니다.

6. 관련 정책

앱은 YouTube API 서비스를 사용하며, 이용 시 YouTube 서비스 약관 과 Google 개인정보처리방침 이 함께 적용됩니다. 앱의 Google API 데이터 사용은 Google API Services User Data Policy (Limited Use 요구사항 포함)를 따릅니다.
