기묘한 기록 (StrangeRecords)

미스터리 · 기묘한 현상 · 전설의 생물 · 숨겨진 역사를 다루는 YouTube Shorts 채널의 자동 제작 도구

기묘한 기록은 채널 운영자 본인이 사용하는 개인용 도구입니다. 매일 주제를 정하고 대본, 음성, 자막, 영상을 만든 뒤 YouTube Data API v3 로 운영자 본인의 YouTube 채널에 업로드합니다. 다른 사용자의 계정에 접근하거나 다른 사용자의 데이터를 수집하지 않습니다.

YouTube API 사용 범위

  • youtube.upload: 제작한 Shorts 영상을 운영자 본인 채널에 업로드
  • youtube.readonly: 업로드한 영상의 공개 상태·공개 통계 확인
  • yt-analytics.readonly (선택): 운영자 채널 영상의 성과 지표 조회
  • youtube.force-ssl (선택): 공개된 영상에 영상 내용에 관한 채널 댓글 1개 등록, 운영자가 실행할 때만 채널 소개·배너 수정

댓글 고정, 채널 프로필 사진 변경은 API 로 하지 않으며 운영자가 YouTube Studio 에서 직접 처리합니다. 영상의 대본·음성·장면 이미지는 AI 를 활용해 만들며, AI 이미지는 실제 기록 사진이 아닌 재현 이미지입니다.
