기묘한 기록 (StrangeRecords)

미스터리 · 기묘한 현상 · 전설의 생물 · 숨겨진 역사를 다루는 YouTube Shorts 채널의 자동 제작 도구

기묘한 기록은 채널 운영자 본인이 사용하는 개인용 도구입니다. 매일 주제를 정하고 대본, 음성, 자막, 영상을 만든 뒤 YouTube Data API v3 로 운영자 본인의 YouTube 채널에 업로드합니다. 다른 사용자의 계정에 접근하거나 다른 사용자의 데이터를 수집하지 않습니다.

YouTube API 사용 범위

  • youtube.upload: 제작한 Shorts 영상을 운영자 본인 채널에 업로드
  • youtube.readonly: 업로드한 영상의 공개 상태 확인
